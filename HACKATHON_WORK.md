# Hackathon work

New work planned and implemented for the Nebius x NVIDIA Global AI Hackathon 2026:

- RAME Agent Server and recoverable agent loop.
- Runtime integration with NVIDIA Nemotron through Nebius Token Factory.
- Separation of observations, proposals, authorized decisions, and action permissions.
- Version checks at action execution time.
- Server-signed, publicly verifiable authorization receipts.
- Document-to-task and calendar workflow.
- Consequence previews and selective repair of proposal, plan, and task results.
- Preservation of compatible human edits, stable task identity, and independent results.
- Atomic conflict detection when a result changes after a repair preview.
- Adversarial document and stale-session demonstrations.
- Reproducible deterministic and model-backed evaluations.
- Same-model, same-context comparison against a reference executor without RAME version guards.
- English-first bilingual web experience and deployment.
